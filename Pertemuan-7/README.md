# Tugas Praktikum Modul Flutter

Project Flutter ini berisi contoh penggunaan beberapa widget UI dasar sesuai instruksi tugas.

## Widget yang Digunakan

1. **Container**
   Digunakan untuk membuat kotak berwarna hijau dengan teks di tengah.

2. **GridView**
   Digunakan untuk menampilkan 6 item dalam bentuk grid 3 kolom.

3. **ListView**
   Digunakan untuk menampilkan 3 item sederhana, yaitu A, B, dan C.

4. **ListView.builder**
   Digunakan untuk membuat list dari data array `dataMahasiswa` secara dinamis.

5. **ListView.separated**
   Digunakan untuk menampilkan list mata kuliah dengan garis pembatas antar item.

6. **Stack**
   Digunakan untuk membuat tampilan bertumpuk berupa beberapa kotak dan teks di atasnya.
